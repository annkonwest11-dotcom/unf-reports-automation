# Ставки и KPI — единый справочник

Где что лежит в системе расчёта зарплаты. Три источника: **код**, **таблица
СМЕНЫ**, **внешняя KPI-таблица**. Пустые поля (❓) — дозаполнить вручную.

**Обновлено:** 2026-07-06

## 1. Ставки, зашитые в коде

Файл: `sheets.py`. Меняются только правкой кода.

### 1.1. Менеджер «сопровождение», выходной день
Функция `_shift_value` (`sheets.py`).

| Условие | Ставка |
|---|---|
| 2 телефона + фирмы | 3900 ₽ |
| 1 телефон + фирмы | 3600 ₽ |
| 2 телефона, без фирм | 2100 ₽ |
| 1 телефон, без фирм | 1800 ₽ |

> В будни у «сопровождения» ставка берётся из таблицы (см. раздел 2), не из кода.

### 1.2. Влада (Владислава Герасимчук)

| День | Что | Ставка |

| Будний | подработки | 2500 ₽ |
| Выходной | подработки | 2000 ₽ |
| Без поля «заказы» (старый шаблон) | основные | ставка из таблицы, иначе 3000 ₽ |

### 1.3. Анна (РОП)
Функция `write_shift` (`sheets.py`), авто-смена в 11:00 по будням.

| Что | Ставка |
|---|---|
| Смена | ставка из таблицы (колонка D), иначе **5000 ₽** |

Схема оплаты Анны (фикс / переменная), наличие KPI: ❓ **уточнить**

### 1.4. Расшифровка типов подработки
Функция `_section_side_job_stats` — по сумме в ячейке определяется категория
(обратно к ставкам выше). Важно: если ставки в 1.1 изменятся, эта расшифровка
сломается, её нужно менять синхронно.

| Сумма в ячейке | Категория |
|---|---|
| 1800 | рест.1тел |
| 2100 | рест.2тел |
| 3600 | фирмы+1тел |
| 3900 | фирмы+2тел |

## 3. KPI

### 3.1. В коде
Единственная метрика — `CALLS_NORM = 20` (`bot.py`). Для менеджера «поиск»:
если звонков за смену меньше 20 → алерт Анне в личку.

### 3.2. Внешняя KPI-таблица
Основной KPI считается **в отдельной Google-таблице**, в коде его нет.

| Параметр | Значение |
|---|---|
| KPI-таблица (источник) | `1QuvmjSPJUbqGTbGKKBcDu8QdQaFv1Gg2VbzUb-bEbL4` |
| Зарплатная таблица (приёмник) | `1KaxfaSWTDR31eAJfmpahaNwaO2Qohrh5xua1Rrjf2Zo` |
| Скрипт синхронизации | `scripts/sync_kpi.py` |
| Как работает | берёт **последний лист** KPI-таблицы → пишет в лист `КПИ_ДАННЫЕ` зарплатной таблицы |
