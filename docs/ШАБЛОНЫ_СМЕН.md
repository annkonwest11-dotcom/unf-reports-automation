# 📋 Шаблоны смен для сотрудников

Отправлять боту в рабочий групповой чат. Дата — только число месяца.
Обязательно ставить **двоеточие** после названия поля и писать ответ после него.

---

## Влада (помощник руководителя)

```
Смена Влада
Сотрудник: Владислава Герасимчук
Дата: 15
Выполненные задачи: коротко о сделанном
Заказы будни (да/нет): нет
Заказы выхи (да/нет): нет
```

**Как заполнять поле «Заказы»:**

| Ситуация | Что писать | Начислит |
|---|---|---|
| Будний день, были заказы | `Заказы будни (да/нет): да` | осн. смена 3000 + подработка 2000 |
| Будний день, заказов не было | `Заказы будни (да/нет): нет` | только осн. смена 3000 |
| Выходной, работала с заказами | `Заказы выхи (да/нет): да` | подработка 2000 (осн. смены нет) |
| Выходной без работы | смену можно не отправлять | — |

Правило простое: основная смена 3000 ставится всегда, **кроме** случая «Заказы выхи: да»
(тогда только подработка 2000).

## Менеджер сопровождения (Алена)

```
Смена Менеджер сопровождение
Сотрудник: Алена Черкашина
Дата: 15
Выполненные задачи: коротко о сделанном
Тип (выходной/будний): будний
Фирмы (да/нет): нет
Заказы выходные (телефонов 1/2):
Заказы будние (доп телефон да/нет): нет
```

**Как считается:**

- **Тип «будний»** → основная смена **2500**
- **Тип «выходной»** → основной смены нет
- **Фирмы: да** → +**1800** к подработке (в любой день — и будни, и выходной)
- **Заказы выходные** (только в выходной): 1 телефон → +**1800**, 2 телефона → +**2100**
- **Заказы будние доп.телефон: да** → +**1800**

**Примеры:**

| Ситуация | Начислит |
|---|---|
| Будни + фирмы да | осн. 2500 + подработка 1800 |
| Будни + доп.телефон да | осн. 2500 + подработка 1800 |
| Выходной + 1 телефон (без фирм) | подработка 1800 |
| Выходной + 2 телефона (без фирм) | подработка 2100 |
| Выходной + фирмы да + 1 телефон | подработка 3600 |
| Выходной + фирмы да + 2 телефона | подработка 3900 |

## Менеджер поиска (Дарья, Ксения, Валерия Папоян)

```
Смена Менеджер поиск
Сотрудник: Дарья Вольнова
Дата: 15
Выполненные задачи: коротко о сделанном
Звонки всего: 25
```

Начислит основную смену **2500** за день. Норма звонков — 20+ в день.

## РОП (Анна)

Смену вносить не нужно — бот ставит её автоматически (5000 ₽) каждый будний день в 11:00.
