---

## ⚡ Что скрипт делает:

1. ✅ Проверяет требования (Python, Node.js, clasp)
2. ✅ Создает структуру проекта Google Apps Script
3. ✅ Загружает файлы конфигурации и основного кода
4. ✅ **Развертывает как Web App** и получает Deployment URL
5. ✅ Подготавливает расширение 1С с правильным URL
6. ✅ Выводит инструкции что делать дальше

## 🚀 БЫСТРЫЙ СТАРТ (1 команда)

### Шаг 1: Установить требования

Если на Mac с Homebrew:
```bash
brew install node
npm install -g @google/clasp
clasp login  # Авторизуйся в своем Google аккаунте
```

Если на Linux/Windows:
```bash
# Установи Node.js с https://nodejs.org
npm install -g @google/clasp
clasp login
```

### Шаг 2: Запустить скрипт установки

```bash
cd /Users/anna/claude-test
bash run_full_setup.sh
```

**Это сделает всё автоматически!** ✨

## 📝 После скрипта нужно:

### 1. Создать листы в Google Sheets (5 минут)

Открой: https://docs.google.com/spreadsheets/d/11XIw2dHpEF6EOxX9QlNFGbPwCjМАЗzYwbJpJtl_tТc/

Создай листы:
- `RAW_perfilev`
- `RAW_gubarev`
- `DASHBOARD`
- `LOG`
- `QUEUE`

(Подробности в QUICK_START_5MIN.md)

### 2. Загрузить расширение в 1С (10 минут)

Файл расширения будет в:
```
/Users/anna/claude-test/UNF_EXTENSION_WITH_URL.bsl
```

Для каждой базы (Перфильев и Губарев):
1. Открой 1С Конфигуратор
2. **Конфигурация → Расширения → Загрузить**
3. Выбери файл `UNF_EXTENSION_WITH_URL.bsl`
4. **Установить**
5. **Сохрани** (Ctrl+S)

(Подробности в 1C_EXTENSION_SETUP.md)

### 3. Создать регламентные задания в 1С (5 минут)

**Ежедневная отправка:**
- Администрирование → Регламентные задания → Новое
- Процедура: `УНФ.ОтправкаОтчетовРегламент`
- Расписание: Ежедневно 09:30 МСК

**Опрос очереди команд:**
- Администрирование → Регламентные задания → Новое
- Процедура: `УНФ.ОпросОчередиКомандРегламент`
- Расписание: Каждую минуту

(Подробности в 1C_EXTENSION_SETUP.md)

## 🆘 Если что-то пошло не так

### "clasp не найден"
```bash
npm install -g @google/clasp
```

### "Не авторизован"
```bash
clasp logout
clasp login
```

### "Deployment не удался"
- Проверь интернет соединение
- Проверь права доступа в Google аккаунте
- Попробуй снова: `bash run_full_setup.sh`
