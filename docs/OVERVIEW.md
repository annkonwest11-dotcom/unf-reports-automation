# 🎯 Описание проекта

## Что это?

**Единая система управления ботом и отчётами** для облачной 1С (42clouds).

Автоматизирует:
1. 📋 Учёт смен сотрудников (в Telegram → Google Sheets)
2. 📊 Отправку отчётов из 1С (OData → Telegram)
3. 🔄 Синхронизацию данных (1С → Google Sheets)
4. 📅 Архивирование месячных данных

---

## Для кого?

- **Анна (РОП)** — управляет ботом, смотрит отчёты
- **Сотрудники** — пишут отчёты о смене в чат
- **Руководство** — видит отчёты в Telegram и Google Sheets

---

## 🏭 Как это работает?

### Вариант 1: Отчёт о смене
```
Сотрудник в чат:
"смена 25 5 100 рест.1тел:2 250"
    ↓
Bot парсит и сохраняет в Google Sheets лист СМЕНЫ
    ↓
Анна видит отчёт в таблице (автоматически)
```

### Вариант 2: Отчёт из 1С
```
Анна в личку боту:
"/reports_perfilev 25.06 25.06"
    ↓
Bot загружает данные из OData (1С API)
    ↓
Бот отправляет красивый отчёт в Telegram
```

### Вариант 3: Синхронизация
```
Анна пишет: "/sync_1c"
    ↓
Bot загружает дебиторку и взаиморасчёты из 1С
    ↓
Сохраняет в Google Sheets листы ИНТЕГРАЦИЯ и ВЗАИМОРАСЧЁТЫ
```

## 📈 Масштаб

- **2 базы 1С:** Перфильев (152757) и Губарев (64904)
- **~15 сотрудников** (пишут отчёты)
- **1 группа чата + 1 личка** (Анна)
- **1 Google таблица** (хранилище)
- **~50 листов** в таблице

---

## 💾 Хранилище данных

**Google Sheets** с листами:
- `СМЕНЫ` — отчёты о смене
- `СВОДНАЯ_ЗП` — расчёты зарплаты
- `ИНТЕГРАЦИЯ` — дебиторка (из 1С)
- `ВЗАИМОРАСЧЁТЫ` — взаиморасчёты (из 1С)
- `DASHBOARD` — сводный дашборд
- `LOG` — логи операций
- `RAW_perfilev`, `RAW_gubarev` — сырые данные из 1С

---

## 🔐 Безопасность

- **Аутентификация:** User ID в Telegram
- **Авторизация:** Только Анна может делать критичные операции (/sync_1c, /archive)
- **Credentials:** В `.env` и Google Properties
- **OData auth:** Basic Auth (api_bot:password)

## ⚡ Примеры команд

### Пользователи (сотрудники)
```
смена 25 5 100 рест.1тел:2 250
```

### Анна (административные)
```
/start                          # регистрация
/sync_1c                        # синхронизация из 1С
/archive                        # архивирование месяца
/смена 25.06                   # получить отчёт за день
смена 25.06                    # то же самое
/reports_perfilev 25.06 25.06  # отчёты Перфильева
/reports_gubarev 25.06 25.06   # отчёты Губарева
/reports 25.06 25.06           # отчёты обеих баз
/today                         # отчёт за сегодня
/range 01.06 30.06            # отчёт за период
```

## 📊 Главные метрики

Что отслеживает система:
- ✅ Количество смен каждого сотрудника
- ✅ Сумма доход от смен
- ✅ Продажи из 1С (по дате)
- ✅ Дебиторка (общая и просрочено)
- ✅ Взаиморасчёты (нам должны / мы должны)
- ✅ Активность клиентов (заказы в период)
