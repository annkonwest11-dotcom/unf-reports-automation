## 2. Зарплата — база (ставки)

### 2.1. Из чего складывается базовая часть?

**Структура отчёта о смене:**

Сотрудник пишет в чат:
```
смена 25 5 100 рест.1тел:2 250
      │ │ │   │            │
      │ │ │   │            └─ Сумма подработок (250 ₽)
      │ │ │   └─ Категория подработок (рест.1тел = ресторан, 1 телефон)
      │ │ │      Количество: 2
      │ │ └─ Сумма основных смен (100 ₽)
      │ └─ Количество основных смен (5)
      └─ Дата (25 число)
```

**Разбор:**
- **Основные смены** (или просто "смены"):
  - Количество смен
  - Сумма за все смены (в Google Sheets это вычисляется как `количество × ставка`)
  
- **Подработки** (дополнительная работа):
  - 4 типа (рест.1тел, рест.2тел, фирмы+1тел, фирмы+2тел)
  - Для каждого типа: количество и сумма
  - Сумма = количество × ставка за подработку

**Итого в день:**
```
Зарплата = (основные смены × ставка смены) + (подработки × ставка подработки)
```

### 2.3. Подработки считаются? как

**ДА, считаются!** 

**Структура (из sheets.py):**
```
Подработки разбиваются на 4 категории:
1. рест.1тел      — ресторан, 1 телефон
2. рест.2тел      — ресторан, 2 телефона
3. фирмы+1тел     — фирмы, 1 телефон
4. фирмы+2тел     — фирмы, 2 телефона
```

**Как подсчитываются:**
```
В Google Sheets лист СМЕНЫ:
├─ Раздел "основные смены"
│  └─ Столбцы: ФИ, пн, вт, ср, чт, пт, сб, вс, Итого дни, Итого сумма
│
└─ Раздел "подработки"
   └─ ФИ | рест.1тел | рест.2тел | фирмы+1тел | фирмы+2тел | Итого сумма
```

**Пример:**
```
Валерия:
  Основные смены: 5 дней × 1000 ₽ = 5000 ₽
  Подработки:
    - рест.1тел: 3 × 500 = 1500 ₽
    - рест.2тел: 2 × 600 = 1200 ₽
    - фирмы+1тел: 1 × 400 = 400 ₽
    - фирмы+2тел: 0 × 700 = 0 ₽
  Подработки итого: 3100 ₽
  ИТОГО: 5000 + 3100 = 8100 ₽
```

## ⚙️ Как это работает в коде

### bot.py
```python
# Пример парсинга смены:
text = "смена 25 5 100 рест.1тел:2 250"
# ↓ парсится в:
report = {
    'date': '25',
    'main_shifts': 5,          # кол-во основных смен
    'main_amount': 100,        # сумма (вводит сотрудник)
    'side_work': {
        'рест.1тел': 2         # кол-во
    },
    'side_amount': 250         # сумма
}
```

### sheets.py
```python
# Что происходит:
sheets.update_report(report)
# ↓
# 1. Находит строку сотрудника в листе СМЕНЫ
# 2. В раздел "основные смены" вставляет сумму и кол-во
# 3. В раздел "подработки" вставляет данные по категориям
# 4. Пересчитывает итоговые формулы
# 5. Данные попадают в СВОДНАЯ_ЗП (автоматически через формулы)
```
