### 1. Дублирование кода OData
**Severity:** HIGH  
**Status:** OPEN  
**Дата обнаружения:** 2026-06-20  

**Описание:**
```
OData парсер существует в двух местах:
1. telegram_reports.py (Python)
2. Code.gs (Google Apps Script)

Это означает:

- [ ] Убрать логику из `telegram_reports.py`

### 3. Нет обработки ошибок OData
**Severity:** MEDIUM  
**Status:** OPEN  

**Описание:**
```
OData запросы могут упасть:
- Сеть недоступна → какой ответ?
- Timeout (>30s) → зависание бота?
- 401 Unauthorized → как узнать?
- 404 Not Found → как узнать?
```

**Текущее поведение:**
```

❌ Нет timeout
❌ Нет retry логики
❌ Пользователь ждёт без ответа
```

**Решение:**
- [ ] Добавить timeout (10s максимум)
- [ ] Добавить retry (до 3 раз)
- [ ] Добавить try-except
- [ ] Вернуть ошибку пользователю

### 4. OData слишком медленно
**Severity:** MEDIUM  
**Status:** OPEN  
**Дата обнаружения:** 2026-06-23  

**Описание:**
```
Время загрузки данных из OData:
- Продажи: ~2s

**Решение:**
- [ ] Добавить кэширование (in-memory или Redis)
- [ ] Добавить паджинацию
- [ ] Оптимизировать $filter запросы
- [ ] Асинхронная загрузка данных
