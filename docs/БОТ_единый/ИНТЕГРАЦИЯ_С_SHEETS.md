## 2️⃣ ЛИСТЫ ДАННЫЕ — Откуда брать ФАКТЫ

**Из скрина видно:**
- Лист "ДАННЫЕ — Губарев" (отчеты из 1С Губарев)
- Лист "ДАННЫЕ — Перфильев" (отчеты из 1С Перфильев)

**Нужно читать:**

### ФАКТ НОВЫХ ПРОДАЖ (Блок 2):
- **Источник:** Лист "новые клиенты"
- **Что считать:** Сумма новых клиентов за месяц в разрезе РОП
- **Колонка:** Нужно уточнить название (видимо есть колонка "Оплаты новых" или "Новые клиенты сумма")

### ФАКТ ОБОРОТА (Блок 3):
- **Источник:** Листы ДАННЫЕ Губарев + Перфильев
- **Что считать:** "Увеличение долга" (это оборот, продажи)
- **В коде:** Сумма из AccumulationRegister_Продажи за период

### ФАКТ ПОСТУПЛЕНИЙ (Блок 4):
- **Источник:** Листы ДАННЫЕ Губарев + Перфильев
- **Что считать:** "Уменьшение долга контрагента" (это оплаты поступившие)
- **В коде:** Сумма из AccumulationRegister_РасчетыСПокупателями (Receipt) за период
