#### Для МЕНЕДЖЕРОВ ПОИСКА (как было):
```
Компонент (название сотрудника)
  └─ Смены: кол-во × 2500
  └─ Оплаты (все клиенты): авто из 1С
  └─ Оплаты (новые клиенты): авто из НОВЫЕ_КЛИЕНТЫ
  └─ % выполнения плана: авто расчет
  └─ Фикс.бонус (KPI): авто по таблице
  └─ % от оплат (ставка): авто по таблице
  └─ Бонус % от оплат: авто расчет
  └─ Конкурс (бонусы): авто из КОНКУРС
  └─ Дополнительная премия: вручную
  └─ Комментарий
  └─ ИТОГО
```

#### Для ВЛАДЫ (Владислава Герасимчук):
```
Компонент (Владислава Герасимчук | Помощник руководителя)
  └─ Смены: кол-во × 3000
  └─ Подработки: авто по типам
  └─ HR оклад: 25000 (авто из НАСТРОЙКИ)
  └─ HR за найм — менеджеры 7 дней: вручную кол-во × 5000
  └─ HR за найм — менеджеры месяц: вручную кол-во × 20000
  └─ HR за найм — производство месяц: вручную кол-во × 10000
  └─ HR за найм — водители месяц: вручную кол-во × 20000
  └─ HR за найм — план найма: вручную 0 или 20000
  └─ SMM оклад: 25000 (авто из НАСТРОЙКИ)
  └─ SMM премия контента: вручную 0 или 5000
  └─ Проекты премии: вручную сумму
  └─ Логистика (макс 10000): вручную сумму (10000 или менее в зависимости от ошибок)
  └─ Дополнительная премия: вручную
  └─ Комментарий
  └─ ИТОГО (авто сумма всех)
```

#### Для РОП (Анна Кономенко):
```
Компонент (Анна Кономенко | РОП — Руководитель отдела продаж)
  └─ Смены: кол-во × 5000 (авто)
  └─ Блок 2 — Новые продажи:
      └─ Факт оплат: авто из НОВЫЕ_КЛИЕНТЫ
      └─ % выполнения плана: авто (факт / план × 100%)
      └─ Фикс.бонус (KPI): авто по таблице (70%→0, 100%→1%, 115%→+10k)
      └─ % от оплат (ставка): авто (70%→0.7%, 100%→1%)
      └─ Бонус % от оплат: авто (факт × %)
      └─ Премия 115%: авто (10000 если факт ≥ 115% плана)
  └─ Блок 3 — Оборот:
      └─ Факт оборота: авто из ДАННЫЕ (увеличение долга)
      └─ % выполнения плана: авто
      └─ Бонус: авто (70%→0.7%, 100%→1% от факта)
  └─ Блок 4 — Поступления:
      └─ Факт поступлений: авто из ДАННЫЕ (уменьшение долга)
      └─ % выполнения плана: авто
      └─ Бонус: авто (70%→0.7%, 100%→1% от факта)
  └─ Дополнительная премия: вручную
  └─ Комментарий
  └─ ИТОГО (авто сумма всех)
```

## 🤖 КОД БОТ_PROTOTYPE.PY

### ✅ Что уже реализовано:

1. **Парсер смен** — `parse_shift()` (уже был)

2. **KPI менеджеров поиска** — `kpi_poisk()`
   - Таблица порогов 50% → 200%
   - Фикс-бонус + % от оплат

3. **KPI РОП** — `kpi_rop_block()` и `kpi_rop_premium()`
   - Логика 70%/100% плана
   - Премия 115%+ (только блок 2)

4. **Структуры данных** — `SalaryRow`
   - Поля для всех KPI (vlada_hr, vlada_smm, rop_new_sales и т.д.)

5. **Расчет ЗП** — `compute_salary()`
   - По группам (poisk, vlada, rop, soprovozhdenie)
   - С учётом всех KPI

6. **Функции чтения из Google Sheets** — `_read_settings_plans()`, `_read_rop_facts()`
   - Читают планы РОП из НАСТРОЙКИ (строки 13-15)
   - Читают автокомпоненты Влады из НАСТРОЙКИ (строки 17-19)
   - Читают факты РОП из листов НОВЫЕ_КЛИЕНТЫ и ДАННЫЕ

7. **Вывод в СВОДНАЯ_ЗП** — в методе `run()`
   - По-разному для каждой группы
