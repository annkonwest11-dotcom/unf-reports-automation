**Компонент:** Владислава Герасимчук | Помощник руководителя

Добавлять в таком порядке:

```
| Компонент | Детали / формула | Сумма |
|-----------|------------------|-------|
| Владислава Герасимчук \| Помощник руководителя | | |
| Смены | Смены из СМЕНЫ листа × 3000 (будни) / 2000 (выходные подработки) | АВТО |
| Подработки | Сумма подработок | АВТО |
| HR оклад | Из НАСТРОЙКИ (25000) | 25000 |

| HR за найм — менеджеры месяц | Вводите кол-во × 20000 | ВРУЧНУЮ |
| HR за найм — производство месяц | Вводите кол-во × 10000 | ВРУЧНУЮ |
| HR за найм — водители месяц | Вводите кол-во × 20000 | ВРУЧНУЮ |
| HR за найм — план найма | 0 или 20000 | ВРУЧНУЮ |

| Логистика бонус | Вводите 10000 (или менее если ошибки) | ВРУЧНУЮ |
```

## ПРИМЕРЫ РУЧНОГО ВВОДА

### Влада:
```
Смены: =COUNTIF(СМЕНЫ!C:C,"Владислава")*3000

HR за найм — менеджеры 7 дней: 2  (ввести число)
  → Формула: =2*5000 = 10000

HR за найм — менеджеры месяц: 1  (ввести число)
  → Формула: =1*20000 = 20000

SMM премия контента: 1  (ввести 0 или 1)
  → Формула: =1*5000 = 5000

Проекты премии: 15000  (ввести число)

Логистика бонус: 9500  (ввести финальное число 10k или менее)
```

### РОП (Анна):
```
Смены: =COUNTIF(СМЕНЫ!C:C,"Анна")*5000

Блок 2 факт: =SUMIF(НОВЫЕ_КЛИЕНТЫ!C:C,"Кономенко",НОВЫЕ_КЛИЕНТЫ!G:G)

Блок 2 % плана: =B2/1050000*100  (1050000 из НАСТРОЙКИ)

Блок 2 бонус: =IF(C2<70%,0,IF(C2>=100%,B2*0.01,B2*0.007))
  + Премия: =IF(C2>=115%,10000,0)

Блок 3 факт: =SUMIF(ДАННЫЕ_Губарев!...)+SUMIF(ДАННЫЕ_Перфильев!...)
  (выбрать РОП, колонка оборота)

Блок 3 % плана: =B3/10000000*100  (10000000 из НАСТРОЙКИ)

Блок 3 бонус: =IF(C3<70%,0,IF(C3>=100%,B3*0.01,B3*0.007))

Аналогично Блок 4 (поступления)
```

## 📌 ВАЖНО

- **АВТО** = формула считается автоматически
- **ВРУЧНУЮ** = Анна вводит число каждый месяц
- Не забывать обновлять ПЛАНЫ на листе НАСТРОЙКИ на 1-е число месяца
- ИТОГО всегда считается как сумма всех компонентов
