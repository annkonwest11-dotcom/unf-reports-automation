✅ **БЛОК 4 — ЛОГИСТИКА (бонус администрирования)**
- ✅ БОНУС за администрирование (максимум): 10 000 ₽/месяц

  - B. Ежедневно утром — неподтверждённые точки в отчёт проблем
  - C. Еженедельно (четверг) — отчёт по водителям (опоздания/недовозы)
  - D. По итогам периода — сверка выплат с логистом
  - E. Еженедельно/ежемесячно — отчёт по тайм-слотам и регламенту
- **Реализация:** Ручной ввод (`kpi_inputs["Владислава"]["logistics"]`)
- **Формат:** Вводится финальное число (10 000 ₽ или меньше после вычета за ошибки)

### РОП (АННА КОНОНЕНКО) — 3 БЛОКА БОНУСОВ + ПРЕМИЯ

✅ **БЛОК 1 — ОКЛАД (фиксированная часть, уже была)**
- ✅ Основная смена: 5 000 ₽/смена (рабочие дни)
- ✅ Подработки в выходные:
  - Ведение фирм: 1 800 ₽/смена
  - Ведение ресторанов: 1 800 ₽/смена

✅ **БЛОК 2 — БОНУС за новые продажи (+ ПРЕМИЯ)**
- ✅ План ставится 1-го числа месяца
- ✅ При 100% плана: +1% от факта
- ✅ При 70% плана: +0.7% от факта
- ✅ ПРЕМИЯ за 115%+: +10 000 ₽
- **Реализация:** Функция `kpi_rop_block()` + `kpi_rop_premium()`
- **Формат:** Два входа — `plan_new_sales` и `fact_new_sales`
- **Формула:**
  - Если факт < 70% плана → 0 ₽
  - Если 70% ≤ факт < 100% → факт × 0.7%
  - Если факт ≥ 100% → факт × 1% + (10 000 ₽ если факт ≥ 115%)

✅ **БЛОК 3 — БОНУС за общий оборот**
- ✅ План ставится 1-го числа месяца
- ✅ При 100% плана: +1% от факта
- ✅ При 70% плана: +0.7% от факта
- **Реализация:** Функция `kpi_rop_block()`
- **Формат:** Два входа — `plan_turnover` и `fact_turnover`
- **Формула:** Аналогично Блоку 2, но БЕЗ премии за 115%

✅ **БЛОК 4 — БОНУС за поступления оплат**
- ✅ План ставится 1-го числа месяца
- ✅ При 100% плана: +1% от факта
- ✅ При 70% плана: +0.7% от факта
- **Реализация:** Функция `kpi_rop_block()`
- **Формат:** Два входа — `plan_payments` и `fact_payments`
- **Формула:** Аналогично Блоку 3 (без премии)

**Тестовый пример РОП:**
```python
kpi_rop_input = {
    "Анна Кономенко": {
        "plan_new_sales": 600000,    # БЛОК 2: план новых продаж
        "fact_new_sales": 720000,    # факт 120% → 7200 ₽ (1%) + 10000 ₽ (премия)
        "plan_turnover": 2000000,    # БЛОК 3: план оборота
        "fact_turnover": 1800000,    # факт 90% → 12600 ₽ (0.7%)
        "plan_payments": 800000,     # БЛОК 4: план поступлений
        "fact_payments": 880000,     # факт 110% → 8800 ₽ (1%)
    }
}
# Результат: база 105000 + KPI (17200 + 12600 + 8800) = 143600 ₽
# При 21 смене (5×5 дней в неделе, обычно график) + 0 подработок: 21×5000 = 105000 ₽
```
