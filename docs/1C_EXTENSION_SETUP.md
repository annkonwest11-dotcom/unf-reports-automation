# 📦 Установка расширения 1С

После того как Google Apps Script готов, нужно загрузить расширение в облачные базы.

---

## ⚙️ Подготовка

### 1. Получить Deployment URL из Google Apps Script

После развертывания GAS ты получил URL типа:
```
https://script.google.com/macros/d/Abc123XYZ/usercurrentUserOnly
```

### 2. Открыть файл расширения

Открой файл `/Users/anna/claude-test/docs/UNF_EXTENSION.bsl`

Найди строку с ГАС_URL и замени:
```javascript
КонстантныеПараметры.Вставить("ГАС_URL", "https://script.google.com/macros/d/YOUR_DEPLOYMENT_ID/usercurrentUserOnly");
```

Замени `YOUR_DEPLOYMENT_ID` на реальный ID из твоего Deployment URL.

## 🚀 Загрузка в базу Перфильева (ИП Перфильев)

### Шаг 1: Открыть облачную базу в Конфигураторе

1. Открой 1С Предприятие
2. Выбери базу **ИП Перфильев** (HTTPS://base.42clouds.com/unf/152757/)
3. Выбери **"1С:Конфигуратор"** (или нажми F7)

### Шаг 2: Перейти в расширения

1. **Конфигурация → Расширения**
2. Нажми **"Загрузить расширение"** (или Ctrl+F5)

### Шаг 3: Выбрать файл

1. Выбери файл `UNF_EXTENSION.bsl`
2. Нажми **"Открыть"**

Система покажет:
- Имя расширения: `UNF Reports Integration`
- Версия расширения
- Другие детали

### Шаг 4: Установить расширение

1. Нажми **"Установить"**
2. Конфигуратор применит расширение

Ожидай несколько минут. Появится сообщение:
```
✅ Расширение успешно установлено
```

### Шаг 5: Сохранить базу

1. **Файл → Сохранить** (или Ctrl+S)
2. Дождись завершения сохранения

## 📋 Настройка регламентных заданий

После загрузки расширения в обе базы, нужно создать два регламентных задания.

### Регламентное задание 1: Ежедневная отправка (09:30)

**В ИП Перфильев:**

1. **Администрирование → Регламентные задания → Новое**
2. Заполни:
   - **Наименование:** `ОтправкаОтчетовУНФ`
   - **Назначение:** `Отправка отчетов в Google Sheets`
   - **Процедура:** `УНФ.ОтправкаОтчетовРегламент` (или выбери из списка)
   - **Использование:** включить
   - **Расписание:** 
     - Периодичность: **Ежедневно**
     - Время: **09:30** МСК
     - Временная зона: **Europe/Moscow**
3. Нажми **ОК**

**В ИП Губарев:**

Повтори то же самое (автоматически изменится `base_id`)

### Регламентное задание 2: Опрос очереди команд (каждую минуту)

**В ИП Перфильев:**

1. **Администрирование → Регламентные задания → Новое**
2. Заполни:
   - **Наименование:** `ОпросОчередиКомандУНФ`
   - **Назначение:** `Опрос очереди команд`
   - **Процедура:** `УНФ.ОпросОчередиКомандРегламент`
   - **Использование:** включить
   - **Расписание:**
     - Периодичность: **Каждую минуту**
     - Интервал: 1 минута
3. Нажми **ОК**

**В ИП Губарев:**

Повтори то же самое

## ✅ Проверка установки

### Тест 1: Посмотреть логи

В каждой базе:

1. **Администрирование → Журнал регистрации**
2. Фильтр:
   - **Имя события:** УНФ.ОтправкаОтчетов
   - Дата: сегодня
3. Проверь были ли попытки отправки

### Тест 2: Ручная отправка отчета

**В 1С Конфигураторе:**

1. **Сервис → Выполнить обработку на сервере** (или F8)
2. Введи процедуру:
   ```
   УНФ.ТестЕжедневногоОтчета()
   ```
3. Нажми **Выполнить**

Ожидай сообщение:
```
✅ Отчет отправлен! Проверь логи и Google Sheets
```

### Тест 3: Проверить Google Sheets

1. Открой таблицу: https://docs.google.com/spreadsheets/d/11XIw2dHpEF6EOxX9QlNFGbPwCjMJAZzYwbJpJtl_tТc/
2. Открой лист **RAW_perfilev** (или RAW_gubarev)
3. Проверь добавлены ли новые строки с данными

Если есть новая строка — **всё работает!** ✅

### Тест 4: Отправка команды через Telegram

1. Напиши боту: `/today`
2. Бот добавит команду в очередь (лист **QUEUE**)
3. Через 1-2 минуты 1С опросит очередь и отправит отчет
4. В лист **DASHBOARD** добавятся значения
5. Боту придет отчет в Telegram

## 🆘 Если не работает

### Проблема: "Процедура не найдена"

**Решение:** Убедись что:
- Расширение установлено (Конфигурация → Расширения, должно быть в списке)
- Имя процедуры правильное: `УНФ.ОтправкаОтчетовРегламент`
- Расширение сохранено

### Проблема: "Ошибка авторизации"

**Решение:**
- Проверь что `auth_token` в расширении совпадает с токеном в Google Sheets
- Должен быть: `unf2tg_a7Kд9P2mQ8xL5fR3vT6wZ1nB4hJ0sC`

### Проблема: "Сертификат не проверен"

**Решение:** 1С не может подключиться к Google (проблема с сертификатом HTTPS)

В разделе "Сертификаты" 1С добавь сертификат Google:
1. **Администрирование → Сертификаты**
2. Добавь сертификат script.google.com

Или используй альтернативный способ подключения (если есть).

### Проблема: Данные не появляются в Google Sheets

**Проверь:**
1. Что листы RAW_perfilev, RAW_gubarev существуют
2. Что URL в расширении правильный
3. Посмотри логи в Google Apps Script (View → Execution log)
4. Посмотри логи в 1С (Администрирование → Журнал регистрации)
