## 🤔 Почему это произошло

### Текущий подход (НЕПРАВИЛЬНЫЙ):
1. Python скрипт (`sync_42clouds.py`) запускает браузер (Selenium)
2. Пытается авторизоваться на странице 42clouds
3. Парсит HTML таблицы отчета
4. Копирует данные в Google Sheets

**Проблемы:**
- ❌ 42clouds изменили HTML структуру → селекторы Selenium больше не работают
- ❌ Selenium ломается при изменении интерфейса
- ❌ Получает только один отчет (Взаиморасчеты)
- ❌ Очень медленно
- ❌ Нежелательно для облачных баз (они часто блокируют автоматизацию)

## ✅ ПРАВИЛЬНЫЙ ПОДХОД (По ТЗ)

**Это не ты скрепишь 1С → это 1С сама отправляет данные тебе!**

### Архитектура (из ТЗ):

```
1С: База А          1С: База Б
(Перфильев)         (Губарев)
     │                   │
     │ POST /ingest      │
     └───────────┬───────┘
                 │
            (мы создаём)
                 │
         ┌───────▼────────┐
         │   GAS Web App  │
         │                │
         │ /ingest        │
         │ /pull-commands │
         │ /webhook       │
         └────────┬───────┘
                  │
         ┌────────┴─────────┬──────────┐
         │                  │          │
    Google Sheets      Excel (.xlsx)   Telegram
    (DASHBOARD)        (отправка)      (боту)
```

### Как это работает:

1. **В облачной 1С создаётся РАСШИРЕНИЕ** (код на встроенном языке 1С)
   - Регламентное задание запускается в 09:30
   - Собирает показатели за период (продажи, дебиторка, активность и т.д.)
   - Сериализует в JSON по контракту раздела 7.1 ТЗ
   - Отправляет **исходящий POST запрос** на `/ingest` в GAS Web App
   - Также каждую минуту опрашивает `/pull-commands` для команд по запросу

2. **Google Apps Script Web App (ты создаёшь)**
   - Получает данные от обеих баз (А и Б)
   - Объединяет их
   - Записывает в Google Sheets (листы RAW_*)
   - Генерирует Excel с дашбордом
   - Отправляет в Telegram

**Преимущества:**
- ✅ Надежно (1С сама инициирует)
- ✅ Быстро (нет скрепинга)
- ✅ Масштабируемо (получаешь ВСЕ показатели, не только один отчет)
- ✅ Безопасно (прямой контракт между системами)
- ✅ Соответствует ограничениям облачной 1С (нет webhook на стороне 1С)
