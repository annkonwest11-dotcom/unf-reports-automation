## 🔄 Как восстановить?

### Вариант 1: Быстрое восстановление (если есть резервная копия ID)

1. Найди оригинальный `employees.json` (или попроси сотрудников свои ID Telegram)
2. Запусти скрипт:
   ```bash
   python3 recreate_employees.py
   ```
3. Отредактируй скрипт и заполни реальные ID вместо комментариев

### Вариант 2: Переустановка (без резервной копии)

Попроси каждого сотрудника:
1. Написать боту `@shift_job_bot` в Telegram
2. Отправить команду `/start`
3. Ввести своё имя и фамилию (как в таблице)

После этого они автоматически получат доступ к отправке отчетов.

### Вариант 3: Отправить сообщение в групповой чат

Напиши в групповой чат:

> ⚠️ Внимание! Система регистрации требует повторную регистрацию.
> 
> Каждый напишите боту в личку:
> 1️⃣ `/start`
> 2️⃣ Ваше имя и фамилию
> 
> После этого сможете отправлять отчеты.
