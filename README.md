# Зарплатная система (Telegram-бот + Google Sheets)

Учёт смен сотрудников и расчёт зарплаты через Telegram-бота. Данные складываются
в Google Sheets, где формулы считают итоговую ЗП. Дополнительно подключена
интеграция с 1С:УНФ (отчёты по продажам и дебиторке).

> Актуальное состояние — что работает, что сломано, открытые вопросы — см. **[STATUS.md](STATUS.md)**.

## Как устроено (рабочее ядро)

```
Сотрудник пишет в Telegram: «смена 25 5 100 рест.1тел:2 250»
   → bot.py          принимает и маршрутизирует сообщение
   → parser.py       разбирает текст смены
   → sheets.py       пишет в Google Sheets (лист СМЕНЫ)
   → формулы Sheets  считают итог в листе СВОДНАЯ_ЗП
```

Отдельно: `sync_42clouds_v2.py` — тянет данные из 1С (OData) в Sheets.

## Файлы в корне (только рабочее ядро)

| Файл | Назначение |
|------|-----------|
| `bot.py` | Telegram-бот: приём смен, команды, алерты |
| `parser.py` | Разбор текста смены |
| `sheets.py` | Чтение/запись Google Sheets |
| `sync_42clouds_v2.py` | Синхронизация 1С → Sheets |
| `run_bot.sh` | Запуск бота с автоперезапуском |
| `employees.json` | Telegram ID → имя сотрудника |
| `.env` | Секреты (токен бота, ID таблицы) — **не в git** |
| `credentials.json` | Ключи Google API — **не в git** |

## Папки

| Папка | Что внутри |
|-------|-----------|
| `scripts/` | Утилиты: `generate_reports.py` (крутится в GitHub Actions), `sync_kpi.py`, `sync_novye_klienty.py`, `telegram_reports.py` |
| `scripts/legacy/` | Одноразовые/отладочные скрипты (`check_*`, `find_*`, старая `sync_42clouds.py` v1) — не для регулярного запуска |
| `scripts/deploy/` | Установщики и деплой-скрипты (разовые) |
| `integrations/gas/` | Google Apps Script (`Code.gs`) |
| `integrations/1c/` | Расширения 1С (`*.bsl`) |
| `docs/` | Вся документация (частично устаревшая — сверяйтесь с STATUS.md) |
| `_trash/` | Кандидаты на удаление (логи, дубли, бэкапы). **Можно удалить после проверки.** |

## Запуск

```bash
source venv/bin/activate      # окружение уже создано
python3 bot.py                # запуск напрямую
# или с автоперезапуском:
bash run_bot.sh
```

Зависимости — в `requirements.txt`.
