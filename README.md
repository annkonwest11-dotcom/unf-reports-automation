# 🚀 ПОЛНАЯ ИНТЕГРАЦИЯ 1С → TELEGRAM

## ⚡ ПРОСТО 3 ШАГА

### Шаг 1️⃣ — Установить инструменты (первый раз)

```bash
npm install -g @google/clasp
clasp login
```

Это откроет браузер — просто авторизуйся в своем Google аккаунте.

### Шаг 2️⃣ — Развернуть всё автоматически

```bash
bash /Users/anna/claude-test/DEPLOY_NOW.sh
```

**Скрипт сделает:**
- ✅ Создаст Google Apps Script проект
- ✅ Загрузит весь код
- ✅ Развернет как Web App
- ✅ Получит Deployment URL
- ✅ Подготовит расширение 1С

**Результат:** Файл `1C_UNF_EXTENSION_FINAL.bsl` и URL для 1С

### Шаг 3️⃣ — Ты загружаешь в 1С

**В каждой базе (Перфильев и Губарев):**

1. Открой 1С Конфигуратор (F7)
2. **Конфигурация → Расширения → Загрузить расширение**
3. Выбери файл: `1C_UNF_EXTENSION_FINAL.bsl`
4. Нажми **Установить**
5. Сохрани **Ctrl+S**

**Создай 2 регламентных задания:**

📌 **Ежедневная отправка:**
- **Администрирование → Регламентные задания → Новое**
- Имя: `ОтправкаОтчетовУНФ`
- Процедура: `УНФ.ОтправкаОтчетовРегламент`
- Расписание: **Ежедневно 09:30 МСК**
- Нажми **ОК**

📌 **Опрос очереди:**
- **Администрирование → Регламентные задания → Новое**
- Имя: `ОпросОчередиКомандУНФ`
- Процедура: `УНФ.ОпросОчередиКомандРегламент`
- Расписание: **Каждую минуту**
- Нажми **ОК**
