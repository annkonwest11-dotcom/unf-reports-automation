# Проект: Марина — КПИ и зарплата

Отдельная папка под всё, что связано с работой Марины: КПИ, зарплата, регламенты процессов и скрипты автоматизации.

## Google-таблица (главный рабочий инструмент)

**КПИ Марина:** https://docs.google.com/spreadsheets/d/1XhGBVBYbin56iOUPs944BnQjZJDIKE39pdP_lpr1PIo/edit

### Листы таблицы

| Лист | Назначение |
|------|-----------|
| **ИНСТРУКЦИЯ** | Как пользоваться системой |
| **СМЕНЫ** | Учёт рабочих дней и расчёт ставки |
| **KPI ДАННЫЕ** | Ежедневный ввод показателей по неделям (⚠️ только жёлтые ячейки!) |
| **ИТОГ** | Автоматический расчёт зарплаты и выплат |
| **ЧЕК-ЛИСТЫ** | Задачи по дням недели |
| **РЕГЛАМЕНТЫ** | Подробные регламенты всех процессов |

## Структура папки

```
marina/
├── README.md          — этот файл, обзор проекта
├── docs/
│   ├── KPI.md         — структура КПИ (2 блока, веса, максимумы)
│   └── РЕГЛАМЕНТЫ.md  — регламенты всех процессов Марины
└── scripts/
    └── report_kpi.py  — снимок статуса: КПИ ДАННЫЕ + ИТОГ (зарплата)
```

## Скрипты

**`report_kpi.py`** — read-only отчёт. Подключается к таблице Марины и выводит
текущие КПИ по неделям и итоговый расчёт зарплаты прямо в терминал.

```bash
python3 marina/scripts/report_kpi.py
```

## Как заполнять таблицу

1. **Лист СМЕНЫ:** ставка (B5) + отметить рабочие дни.
2. **Лист KPI ДАННЫЕ:** каждую неделю (вторник) вносить цифры от Влады в жёлтые ячейки.
3. **Лист ИТОГ:** финальная зарплата считается автоматически ✅

**⚠️ Заполнять ТОЛЬКО жёлтые ячейки!** Остальное содержит формулы.
