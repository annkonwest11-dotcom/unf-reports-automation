Дублирует содержимое листа **РЕГЛАМЕНТЫ** в Google-таблице для быстрого доступа.

- Запрашивать накладную у **Алексея**

## 2. Заказ цукини

- **Поставщики:**
  - Большая академическая (дорого, крайний случай): `89192152479` (Telegram/WhatsApp как ИП Губарев)
  - Болотов (дешевле): `89534251456` в Max (как физлицо!)

## 3. Отчёт по перекупу

- **Таблица:** https://docs.google.com/spreadsheets/d/1MTu7whYO05u7PmBdYGjzmgJ62CkpdX7aDW1mGWRL1SM/edit
- При внесении в Адеск сразу вносим в отчёт перекупу
- По пятницам подводим итог в группе «Проблемы с качеством»

## 4. Внесение в Адеск

- **Ссылка:** https://viachesalav.adesk.ru/payments-approval
- **Группы расходов:**
  - Приходы/Расходы Вячеслав (касса Вячеслав)
  - Расходы производство (касса Иван)
- **День внесения:** пн, ср, пт
- ⚠️ Много нюансов! Необходимо созвониться с Владой 1–2 раза
- После внесения отправить скриншот счетов в группу «РАСХОДЫ ПРОИЗВОДСТВО»

## 5. Отчёт по финансовому планированию

- **Таблица:** https://docs.google.com/spreadsheets/d/1GPXmXntzxKqL4D3DeYGqzLdO3hxf37HIElSQ5P8eYpo/edit
- **Процесс по ПН с утра:**
  1. Адеск → «Движение средств» → Фильтр «Текущий год» + «ПО ДНЯМ»
  2. Экспорт файла на комп
  3. Формат ячеек → «Число»
  4. Ctrl+C копируем таблицу
  5. В таблице финпланирования вставляем на «Данные расход»
  6. Меняем A75 «Статья не указана» на «Статья не указана расходы»
  7. Идём на лист месяца, сверяем данные в правом нижнем углу
  8. Если совпадает — скриншот в «Расходы производство»
